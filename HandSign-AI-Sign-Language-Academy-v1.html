05 · What is currently supported

Camera hand tracking

Uses MediaPipe to locate up to two hands and draw 21 landmarks per detected hand.

ASL alphabet model

A browser-ready model is available for static letters A–Y. J and Z require movement-aware recognition. Model input preprocessing still needs validation against the training pipeline before enabling predictions.

ISL alphabet model

A public A–Z TensorFlow/Keras model is available, but this website needs a browser-compatible conversion and verified preprocessing before live ISL predictions can be enabled.
